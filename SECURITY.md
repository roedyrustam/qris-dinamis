# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `2.2.x` | Yes |
| `< 2.2.0` | Upgrade recommended |

## Reporting a Vulnerability

Because **QRIS Dinamis** handles payment payloads, webhook signatures, and merchant API keys, we take security issues seriously.

**Please do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please report security issues privately using **GitHub Security Advisories** (`https://github.com/roedyrustam/qris-dinamis/security/advisories/new`) with:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof-of-concept.
- Suggested remediation (if any).

We will acknowledge receipt within 48 hours and work with you on a coordinated fix and release.
